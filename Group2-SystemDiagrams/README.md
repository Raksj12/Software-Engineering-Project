# System-Level Diagrams — Group 2

This folder contains the team-wide system design diagrams (not tied to a single user story), covering the overall architecture, data model, and structural design of the project.

## Contents

| File | Type | Description |
|------|------|--------------|
| `ArchitectureContextDiagram.png` | Architecture (Context) Diagram | Shows the high-level system boundary and how the system interacts with external actors/systems. |
| `DatabaseSchema_ER_Diagram.png` | Database Schema (ER Diagram) | Shows the entities, attributes, and relationships in the project's data model. |
| `ClassDiagram.png` | Class Diagram | Shows the system's classes, their attributes/methods, and relationships. |
| `ComponentDiagram.png` | Component Diagram | Shows how the system is broken into components/modules and how they interact. |
