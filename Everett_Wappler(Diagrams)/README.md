# User Story Diagrams - Everett Wappler

This folder contains the UML diagrams for BookHaven. Diagrams cover User Stories 1, 2, 8, and 9.

### User Story 1 - Register and Log In

| File | Type | Description |
|------|------|-------------|
| `Use_Case_Diagram(User_Story_1).png` | Use Case Diagram | Models the User and the registration and login use cases |
| `Activity_Diagram(User_Story_1).png` | Activity Diagram | Shows the step-by-step workflow for registering or logging in as a Buyer or Seller |
| `Sequence_Diagram(User_Story_1).png` | Sequence Diagram | Shows the order of messages between the User, Client UI, App Server, and Database for Login and Registration|
